A simple patch collection that brings modern widescreen and resizable window support to **Minecraft Pre-Classic & Classic**.

> **Fork Notice:** This project is a fork of [Widescreen-Fix-for-Minecraft-rd-132211](https://github.com/Nongmoon/Widescreen-Fix-for-Minecraft-rd-132211) by Nongmoon.  
> The original patch was built on `rd-132211`, this fork updated to support newer Pre-Classic and Classic versions.

---

## Features

* **Widescreen Support:** Play cleanly in 16:9 widescreen without stretched visuals (boots into `1280 × 720` in Pre-Classic).
* **Window Resizing:** Drag window borders or maximize the window freely—the game fills the entire window properly instead of leaving empty blue areas in Classic.
* **Vanilla:** Preserves all original features—you can remove this mod anytime without crashing.
* **No Forced Fullscreen (`rd-160052`):** Starts `rd-160052` in a normal resizable window instead of forcing fullscreen on launch.

## Supported Versions & Controls

### Pre-Classic (`rd-132328`, `rd-160052`, `rd-161348`)
| **Key** | **Action** |
| :--- | :--- |
| `L` | Unlock / Lock Mouse Cursor |
| `F11` | Fullscreen |

### Classic (`c0.0.11a`, `c0.0.13a`, `c0.0.13a_03`)
| **Key** | **Action** |
| :--- | :--- |
| `ESC` | Release Mouse / Pause Menu *(built-in)* |
| `F11` | Fullscreen |

### Classic `0.30` (`c0.30`)
| **Key** | **Action** |
| :--- | :--- |
| `ESC` | Release Mouse / Pause Menu *(built-in)* |

*(Note: fullscreen is not supported in `c0.30`.)*

### Not Listed in Official Launcher
| Support |
| :--- |
| ❌ Not Supported |
